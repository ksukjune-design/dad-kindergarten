# 방과후 아빠 유치원

아빠와 여덟 살이 하루 한 편씩 함께 보는 인터랙티브 무비 8편.

**바로 열기 → https://<사용자>.github.io/<저장소>/**

## 태블릿에서 쓰는 법 (권장)

갤럭시탭에서 크롬으로 열고 **⋮ → 홈 화면에 추가**.
주소창이 사라져 세로를 80~100px 더 쓰고, 앱처럼 전체 화면으로 열립니다.

## AI 기능

이 배포본은 정적 호스팅이라 서버가 없습니다. AI 를 쓰려면 화면의 **⚙ AI 설정**에서
제미나이 API 키를 직접 넣으세요. 키는 **그 브라우저에만** 저장되고 이 저장소에는 없습니다.

**AI 를 꺼도 8편 전부 100% 진행됩니다.** 인터넷이 없어도 됩니다.

## 성장 일지

아이가 쓴 글은 그 브라우저 안에만 쌓입니다. 서버로 나가지 않습니다.

## 다시 빌드하려면

```
node tools/bundle.js
node tools/package-ghpages.js
```
