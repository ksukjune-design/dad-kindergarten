## 쓰는 법

- **체크 빠르게 추가**: 입력칸에 `우리은행 방문 ~10/15 !중요 @아내` 처럼 쓰면 마감일·중요도·담당이 함께 들어갑니다.
  (`~내일`, `~D-3`(이사 3일 전)도 됩니다)
- **도면**: 도면은 평면도 이미지를 구하지 못해 면적·연식·구조로 **추정한 것**입니다. 사전방문 때 실측한 뒤
  `✏️ 치수 수정`으로 방 크기를 고쳐 주세요. 짐 목록에 실제 규격을 넣으면 배치와 견적이 같이 바뀝니다.
- **견적**: 업계 통상 단가로 계산한 **추정치**입니다. 방문견적을 받으면 `업체 견적 비교`에 넣고 `견적으로 보정`을 누르세요.
- **태블릿·휴대폰**: 크롬으로 열고 **⋮ → 홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

## 기록은 어디에 저장되나요

- 모든 체크·메모·짐 목록·도면 배치는 **그 브라우저 안에만** 저장됩니다. 서버로 나가지 않습니다.
- 다른 기기나 배우자와 맞추려면 오른쪽 위 `⋯` → **백업 파일 저장** → 다른 기기에서 **백업에서 복원** 하세요.
- 브라우저 데이터를 지우면 기록도 지워지니, 중요한 날 전에는 백업해 두세요.

## 개인정보

이 저장소는 공개입니다. 그래서 앱 안에는 이름·주민번호·전화번호·계좌번호·동·호수를 넣지 않았고,
집주인은 A(지금 집)·B(매수인)·C(새 집)로 적었습니다. 금액과 일정은 계획에 필요한 만큼만 들어 있습니다.

## 파일 구조 (개발용)

```
move/
├── index.html            앱 틀
├── css/app.css           공용 스타일 (아빠 유치원과 같은 색 토큰, 다크 모드)
└── js/
    ├── core.js           저장·화면 이동·체크리스트/짐 목록 API·공용 UI (계약 설명은 파일 머리말)
    ├── data-seed.js      기본 파트·할 일·짐 목록 (version 을 올리면 기존 기록은 두고 새 항목만 추가)
    ├── data-plans.js     두 집 도면, 규격 프리셋, 두 집 차이 요약
    ├── data-guides-a.js  가이드: 통장업무·행정·아이 취학·이사당일
    ├── data-guides-b.js  가이드: 업체소통·가전이사·짐정리·버리기·가구구매·사전방문·공간설계
    ├── view-*.js         화면별 코드 (홈·체크·도면·견적·자금·가이드)
    └── app.js            메뉴·상단바·백업 메뉴·시작
```

빌드 과정은 없습니다. 파일을 고치고 올리면 그대로 반영됩니다.
날짜를 바꿔 보며 확인하려면 주소 뒤에 `?today=2026-10-20` 처럼 붙이세요.
