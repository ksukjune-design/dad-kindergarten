## 쓰는 법

- **체크 빠르게 추가**: 입력칸에 `우리은행 방문 ~10/15 !중요` 처럼 쓰면 마감일·중요도가 함께 들어갑니다.
  (`~내일`, `~D-3`(이사 3일 전)도 됩니다)
- **할 일은 사람별로 나누지 않아요**: 모든 할 일은 '우리 집 할 일'이에요. 누가 할지 정하는 칸은 없고, 그날그날 편하게 나눠 하면 돼요. 예전처럼 `@아내`를 붙여도 제목에서 빼고 저장해요.
- **도면**: 실제 평면도를 구하지 못해 면적·연식·구조로 **추정한 도면**입니다. 부동산 앱의 평면도를 캡처해
  `🖼 평면도 사진`으로 깔고 `📏 축척 맞추기` 한 뒤, 사전방문 때 실측해서 `✏️ 치수 수정`으로 고쳐 주세요.
- **견적**: 업계 통상 단가로 계산한 **추정치(참고용)**입니다. 이사업체는 10/8 계약해서 자금 화면은 계약 금액으로 계산해요. 짐이 늘어 추가요금이 생길지 볼 때 쓰고, 다른 견적을 받으면 `업체 견적 비교`에 넣어 `견적으로 보정`을 누르세요.
- **AI 비서**: 질문할 때마다 이 계정의 클로드 사용량을 씁니다. 비서가 바꾼 내용은 답 아래 '변경 n건'에서 한 번에 되돌릴 수 있습니다.
- **태블릿·휴대폰**: 크롬으로 열고 **⋮ → 홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

## 기록은 어디에 저장되나요

- **클로드 공유 버전**: 공유 저장소에 저장되어 부부가 같은 기록을 봅니다. 서로 다른 항목은 덮어쓰지 않고, 같은 칸을 동시에 고치면 합칩니다(둘 다 다른 값으로 고친 칸은 한쪽 값으로 정해짐).
- **깃허브 페이지 버전**: 처음에는 그 브라우저 안에만 저장됩니다. 다른 기기와는 `⋯ → 백업 파일 저장 / 백업에서 복원`으로 옮기세요.
- **깃허브 페이지 버전 + 함께 쓰기**: `⋯ → 함께 쓰기 설정`(주소 `#/together`)에서 안내대로 파이어베이스(구글의 무료 데이터베이스)에 우리 집 전용 저장소를 한 번 만들고(약 15분), 각자 이메일·비밀번호로 로그인하면 기록이 그 데이터베이스에 저장되어 부부가 같은 기록을 봅니다. 서로 다른 항목은 덮어쓰지 않고, 같은 칸을 동시에 고치면 합칩니다. 아내는 화면의 초대 링크를 카카오톡으로 받아 열고 로그인하면 됩니다. 규칙에 적은 두 계정 말고는 아무도 읽거나 쓸 수 없고, 무료 요금제로 충분합니다. 로그아웃해도 이 기기 기록은 남고, 연결이 끊기거나 로그아웃한 동안 바꾼 내용은 다시 연결되면 공유 기록과 합쳐서 올립니다.
  - 설정값을 `js/sync-firebase.js` 의 `const BAKED = null;` 에 넣어 두면 초대 링크 없이 앱 주소만 열고 로그인하면 됩니다 (설정값의 apiKey 는 비밀번호가 아니라 공개돼도 되는 값이고, 기록은 규칙이 지킵니다).
- 중요한 날 전에는 `⋯ → 백업 파일 저장`으로 한 번씩 받아 두세요.

## 파일 구조 (개발용)

```
move/
├── index.html            앱 틀
├── css/app.css           공용 스타일 (아빠 유치원과 같은 색 토큰, 다크 모드)
└── js/
    ├── core.js           저장·화면 이동·체크리스트/짐 목록 API·공용 UI·기본값 버전 맞춤
    ├── data-seed.js      기본 파트·할 일·짐 목록 (version 을 올리면 새 항목 추가 + migrations 로 한 번 정리)
    ├── data-plans.js     두 집 도면(추정), 규격 프리셋, 두 집 차이 요약
    ├── data-layouts.js   큰 가전·간이옷장 기본 배치
    ├── data-guides-a.js  가이드: 통장업무·행정·아이 취학·이사당일
    ├── data-guides-b.js  가이드: 업체소통·가전이사·사전 이삿짐 정리·버리기·가구구매·사전방문·공간설계
    ├── data-guides-c.js  별첨: HUG 전세보증금반환보증 — 가입하지 않으면?
    ├── sync.js           공유 저장소 동기화 (클로드 공유 버전 db · 함께 쓰기 어댑터 공통, 3-방향 합치기)
    ├── sync-firebase.js  깃허브 페이지 버전 '함께 쓰기' — 파이어베이스 설정·로그인·어댑터 (설정이 있을 때만 SDK 를 불러옴)
    ├── view-*.js         화면별 코드 (홈·체크·도면·견적·자금·가이드·AI 비서·함께 쓰기)
    └── app.js            메뉴·상단바·백업 메뉴·시작
```
